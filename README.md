# 양수연 2단계 — API로 데이터 불러오기

`index.html`(조회·지도·찜 코스)과 `stamp.html`(스탬프 투어)이 **같은 `api.js`** 로 데이터를 받아요.
둘 중 어느 파일을 더블클릭해도 열립니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html`, `stamp.html` | 화면 두 개 |
| `config.js` | **API 인증키·주소 설정 (여기만 고치면 돼요)** |
| `api.js` | 공통 API 호출 모듈. 위치정보 + 일반정보를 `데이터 고유번호`로 합쳐요 |
| `data.js` | 내장 데이터(CSV 변환본). API를 못 쓸 때 자동으로 사용 |
| `coast.js` | 제주도 해안선(지도 배경) |
| `*.csv` | 원본 CSV (참고용, 화면에서는 읽지 않아요) |

## API 켜는 방법
1. 공공데이터포털에서 아래 두 데이터를 활용신청합니다.
   - 제주특별자치도_제주역사문화위치정보
   - 제주특별자치도_제주역사문화일반정보
2. 마이페이지 → 데이터활용 → Open API → 활용신청 현황 → 각 API 에서
   - **일반 인증키(Decoding)** 복사
   - **요청주소**(`https://api.odcloud.kr/api/.../v1/uddi:...`, `?` 뒤는 빼고) 복사
3. `config.js` 의 `serviceKey`, `locationUrl`, `generalUrl` 에 붙여넣고 저장합니다.
4. 페이지를 새로고침하면 왼쪽 아래에 상태가 표시돼요.

| 표시 | 뜻 |
|---|---|
| 📦 내장 데이터 사용 중 | `config.js` 가 비어 있어서 `data.js` 를 사용 |
| 📡 API에서 120건 불러옴 | API 호출 성공 |
| ⚠️ API 호출 실패 → 내장 데이터 | 키/주소 오류, 네트워크, 브라우저 보안(CORS) 등. 표시에 마우스를 올리면 원인이 보여요 |

## 참고
- API 응답의 필드 이름이 CSV 열 이름(`장소명`, `위도`, `경도`, `분류`, `디렉토리1`, …)과 같다고 가정해요.
  다르면 `api.js` 의 `merge()` 안에서 이름만 바꿔 주세요.
- `config.js` 는 브라우저에서 그대로 보이므로, 사이트를 공개할 때 인증키가 노출돼요.
- 스탬프·찜 기록은 API와 무관하게 이 브라우저(localStorage)에 저장돼요.
